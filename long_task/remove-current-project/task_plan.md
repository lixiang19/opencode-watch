## 关键问题
1. “当前项目”是否只是 UI 标签，还是还影响会话创建与模型/Agent 载入逻辑？
2. 删除这个概念后，项目选择应如何承载“从该目录新建会话”的入口？

## 已做决策
| Decision | Rationale |
|----------|-----------|
| 先梳理 `draftDirectory` 与 `activeProjectDirectory` 的职责 | 当前项目概念看起来与这两个状态强相关，先厘清再改动更安全 |
| 打开会话时不再把会话目录写回 `draftDirectory` | 避免“默认新建目录”被误当成当前项目状态 |
| 聊天头部只展示当前会话目录 | 防止无会话时把默认目录误显示成当前项目 |
