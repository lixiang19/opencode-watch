## 关键问题
1. 如何在尽量少改业务逻辑的前提下引入 Vue Router 并拆分移动端页面？
2. 如何把项目、会话、设置从单页堆叠改为适合手机的一层一屏结构？

## 已做决策
| Decision | Rationale |
|----------|-----------|
| 引入 Vue Router 做移动端多页面信息架构 | 用户明确要求增加路由，且当前单页结构已不适合彻底重构 |
| 保留 `useOpencodeApp` 作为核心状态源 | 现有连接、会话、消息逻辑完整，优先复用业务层 |
| 以根组件 provide/inject 共享应用状态 | 路由切换时保留连接、项目、会话和消息状态 |
| 首页展示项目筛选和会话流，聊天页只保留消息与输入，设置页承载连接表单 | 符合移动端一屏一任务的信息流结构 |
